# Lógica de Programação

Aplicação Front-End desenvolvida com HTML, CSS e JavaScript com foco em exercícios e conceitos de lógica de programação, utilizando interações dinâmicas no navegador.

---

## 📋 Sobre o Projeto

Este projeto tem como objetivo praticar e demonstrar conceitos fundamentais de lógica de programação através de uma interface web simples e interativa.

A aplicação utiliza JavaScript para processamento das regras de negócio e manipulação dinâmica dos elementos da página.

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## 🎯 Funcionalidades

- Estruturas condicionais
- Laços de repetição
- Manipulação de arrays
- Entrada e saída de dados
- Interação dinâmica com o usuário
- Exercícios de lógica implementados no navegador

## ▶️ Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/logica-programacao.git
```

2. Acesse a pasta do projeto:

```bash
cd logica-programacao
```

3. Abra o arquivo `index.html` no navegador.

## 💻 Exemplo de Código

```javascript
function verificarNumero(numero) {
  if (numero % 2 === 0) {
    return "Número par";
  } else {
    return "Número ímpar";
  }
}

console.log(verificarNumero(10));
```
